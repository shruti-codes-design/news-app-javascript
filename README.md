# 📰 News App

A responsive news application built using HTML, CSS, and JavaScript.

## Features

- Search news by keyword
- Fetches news using News API
- Displays article images
- Displays headlines and descriptions
- Shows news source
- Shows publication date
- Read More links
- Error handling
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- REST API
- Fetch API
